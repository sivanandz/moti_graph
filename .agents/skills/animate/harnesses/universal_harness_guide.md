# Universal Animate Skill Adapter (ZCode / DeepSeek / Hermes / OpenCode / Antigravity)
To invoke procedural animation in any agent environment with shell access:
- Windows PowerShell: `.\an.ps1 <command> [args]`
- POSIX / Bash / macOS / Linux: `./an.sh <command> [args]`
- Direct Node CLI: `node .agents/skills/animate/tools/animate.mjs <command> [args]`
Always enforce the 3 Checkpoints (Story -> Look Still -> Storyboard Contact Sheet) before full video rendering.
