# Universal Explainer Video Grammar & Production Directives

Created: 2026-11-09
Source: Distilled from analysis of Vox documentary techniques (Z6R0NvVr164)

## Codified Principles

1. **The 15-Second Inversion Hook**: Open with an immediate cognitive contradiction (`[Familiar Modern Norm]` -> `[Shocking Opposing Origin]`), establishing the central paradox before chronological exposition.
2. **4-Role Semantic Palette**: Strict color discipline: Canvas Grounding, Subject Primary, Counterpoint, and Attention Accent (Highlighter Yellow). No decorative random colors.
3. **Macro-to-Micro 8-Second Pulse**: Continuous camera cycling between aggregate context (system maps, topologies) and micro forensic evidence (tangible memo snippets, isolated cutouts) every 6–10s.
4. **Forensic Data Climax**: Charts/plots enter as the decisive smoking gun resolving the narrative question, with the curve's inflection point timed to the narrator's turning-point sentence.
5. **10-Frame Felt Highlighter Sweep**: Animate organic semi-transparent marker strokes across operative words in 8–12 frames.
6. **Continuous Z-Axis Drift**: Zero static frames (`scale: 1.0 -> 1.05`).
7. **Graphic Match Cuts**: Link disconnected eras through shared center-screen silhouettes.
8. **Audio Ducking**: Abrupt drop to ambient silence during critical pivot points.
